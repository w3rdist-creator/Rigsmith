# Provenance

## Original work in this repository

All application source (`src/`), tests (`tests/`), styles, the UI design, the "Rigsmith"
name and mark (⟁), the `rigsmith.project` / `rigsmith.runtime` file formats, and the
built-in demo character "Tock the tin courier" (rig, animations, and its art, which is
painted procedurally with Canvas 2D at runtime in `src/ui/demoArt.ts`) were written for
this project by the worker (Claude Opus 5.5) on 2026-10-17. Test images are generated by
`tests/e2e/png.ts` at test time.

## What was *not* used

- No Spine (Esoteric Software) executable, installer, trial, runtime library, file
  format specification, example project or art was downloaded, installed, launched,
  opened, inventoried, disassembled or decompiled. The Spine EULA was not accepted.
  The optional "trial metadata inventory" step was skipped as unnecessary.
- No third-party editor source was consulted or copied. Functional requirements come
  from the operator brief and general knowledge of 2D skeletal animation concepts (bones,
  hierarchical transforms, keyframes, interpolation), which are common to many tools.
- No vendor art. No external fonts, CDNs or network services at runtime.

This is an independently written product. That is **not** a legal clean-room
certification, and no such claim is made.
